# Faccat – Exercícios de Lógica de Programação (Java)

Resolução em Java dos exercícios da apostila "Exercícios de Lógica de Programação – Algoritmos" (FACCAT).

## Conteúdo
- `Ex01` a `Ex91`: um arquivo por exercício (atribuições, operadores, seleção, repetição, contadores, maior/menor, repetição aninhada e vetores).
- `Raciocinio1_Rio`, `Raciocinio2_Hanoi`, `Raciocinio3_JesuitasCanibais`: exercícios de raciocínio.
- Exercícios de teste de mesa/análise (2, 3, 4, 23, 34, 39, 43, 77) viraram programas que mostram o resultado.

## Como executar
    javac -encoding UTF-8 -d out *.java
    java -cp out Ex01
